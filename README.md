## Daily Workflow Reference

For every solved problem, record:
1. **Metadata**: Problem number, title, LeetCode link, topic, language, and status.
2. **Thought Process**: Intuition, approach, mistakes/where stuck, and key breakthroughs ("What Clicked").
3. **Solution**: Submitted code with preserved logic and clean formatting.
4. **Analysis & Revision**: Time/space complexity analysis and key takeaways for quick interview revision.
